# OpenAccountants — Ecommerce Seller (vertical)

Industry vertical for e-commerce sellers including Amazon FBA, Shopify, Etsy, eBay, and direct-to-consumer brands. Loaded alongside any country skill to provide industry-specific classification guidance for inventory accounting, marketplace fees, shipping costs, and multi-channel revenue. Trigger phrases — Amazon seller, FBA, Shopify store, Etsy seller, eBay seller, e-commerce, online store, drops

**Powered by the [OpenAccountants](https://openaccountants.com) MCP server** — 1 verified skill(s) for this scope.

## Install

```bash
claude plugin install openaccountants/openaccountants-vertical-ecommerce-seller
```

Or browse the full marketplace:

```bash
claude plugin marketplace add openaccountants/marketplace
```

## Slash commands

- `/start` — scope a workflow and load the right skills
- `/skills` — list every skill in scope
- `/review` — request a licensed accountant to review your work
