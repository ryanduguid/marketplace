# OpenAccountants — Consultant Professional (vertical)

Industry vertical for professional service providers including management consultants, lawyers, architects, accountants, coaches, and advisory professionals. Loaded alongside any country skill to provide industry-specific classification guidance for service-based revenue, WIP accounting, client disbursements, and trust account separation. Trigger phrases — consultant, management consultant, busine

**Powered by the [OpenAccountants](https://openaccountants.com) MCP server** — 1 verified skill(s) for this scope.

## Install

```bash
claude plugin install openaccountants/openaccountants-vertical-consultant-professional
```

Or browse the full marketplace:

```bash
claude plugin marketplace add openaccountants/marketplace
```

## Slash commands

- `/start` — scope a workflow and load the right skills
- `/skills` — list every skill in scope
- `/review` — request a licensed accountant to review your work
