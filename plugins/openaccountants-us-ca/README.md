# OpenAccountants — California

Tax and accounting Guides for California via the OpenAccountants MCP server. Coverage and professional review vary by Guide; check the fetched version's review status.

Guides include accountant-reviewed versions and source-cited drafts. Check each fetched Guide version's review status, reviewer and review date in the [current catalogue](https://www.openaccountants.com/skills).

## Install

```bash
claude plugin install openaccountants/openaccountants-us-ca
```

Or browse the full marketplace:

```bash
claude plugin marketplace add openaccountants/marketplace
```

## Slash commands

- `/start` — scope a workflow and load the right skills
- `/skills` — list every skill in scope
- `/review` — request a licensed accountant to review your work

## Skills in this pack

- `ca-formation`
- `ca-llc-fee-and-tax`
- `ca-payroll`
- `ca-pte-elective-tax`
