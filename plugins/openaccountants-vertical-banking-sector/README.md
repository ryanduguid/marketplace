# OpenAccountants — Banking Sector (vertical)

Use this skill whenever a bank, neobank, payment institution, e-money institution, or regulated financial holding company asks about accounting, regulatory capital, or tax issues specific to financial institutions. Trigger on phrases like "bank tax", "bank levy", "IRB approach", "standardised approach", "IFRS 9 ECL", "FRTB", "Basel III", "Basel IV", "CRR/CRD", "Prudential regulation", "PRA", "ECB 

**Powered by the [OpenAccountants](https://openaccountants.com) MCP server** — 1 verified skill(s) for this scope.

## Install

```bash
claude plugin install openaccountants/openaccountants-vertical-banking-sector
```

Or browse the full marketplace:

```bash
claude plugin marketplace add openaccountants/marketplace
```

## Slash commands

- `/start` — scope a workflow and load the right skills
- `/skills` — list every skill in scope
- `/review` — request a licensed accountant to review your work
