# OpenAccountants — Ohio

Tax and accounting skills for Ohio — 5 verified skill(s) covering income tax, VAT/GST, payroll, formation, bookkeeping, and cross-border issues. Powered by the OpenAccountants MCP server.

**Powered by the [OpenAccountants](https://openaccountants.com) MCP server** — 5 verified skill(s) for this scope.

## Install

```bash
claude plugin install openaccountants/openaccountants-us-oh
```

Or browse the full marketplace:

```bash
claude plugin marketplace add openaccountants/marketplace
```

## Slash commands

- `/start` — scope a workflow and load the right skills
- `/skills` — list every skill in scope
- `/review` — request a licensed accountant to review your work

## Skills in this pack

- `oh-cat`
- `oh-cat-tax`
- `oh-income-tax`
- `oh-payroll`
- `oh-sales-tax`
