# OpenAccountants — Wisconsin

Tax and accounting skills for Wisconsin — 3 verified skill(s) covering income tax, VAT/GST, payroll, formation, bookkeeping, and cross-border issues. Powered by the OpenAccountants MCP server.

**Powered by the [OpenAccountants](https://openaccountants.com) MCP server** — 3 verified skill(s) for this scope.

## Install

```bash
claude plugin install openaccountants/openaccountants-us-wi
```

Or browse the full marketplace:

```bash
claude plugin marketplace add openaccountants/marketplace
```

## Slash commands

- `/start` — scope a workflow and load the right skills
- `/skills` — list every skill in scope
- `/review` — request a licensed accountant to review your work

## Skills in this pack

- `wi-income-tax`
- `wi-payroll`
- `wi-sales-tax`
