# OpenAccountants — South Africa

Tax and accounting Guides for South Africa via the OpenAccountants MCP server. Coverage and professional review vary by Guide; check the fetched version's review status.

Guides include accountant-reviewed versions and source-cited drafts. Check each fetched Guide version's review status, reviewer and review date in the [current catalogue](https://www.openaccountants.com/skills).

## Review provenance

The pack's earlier metadata attributed review to **Werner Britz, CA(SA)**. Check the fetched Guide version's published review record for its reviewer and review date.

## Install

```bash
claude plugin install openaccountants/openaccountants-za
```

Or browse the full marketplace:

```bash
claude plugin marketplace add openaccountants/marketplace
```

## Slash commands

- `/start` — scope a workflow and load the right skills
- `/skills` — list every skill in scope
- `/review` — request a licensed accountant to review your work
